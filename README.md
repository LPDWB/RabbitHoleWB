# Google Antigravity // WMS Intelligence Console

Интеллектуальная система управления статусами WMS, регламентами ТСД и пакетной обработкой штрихкодов в стилистике **Google Antigravity**.

## Возможности

- 🌌 **Google Antigravity Экосистема**: Динамический интерактивный канвас частиц (Zero-G Engine), 4-цветовые градиенты Google и высокоточный квантовый стекломорфизм.
- ⚡ **Каталог статусов WMS (`/`)**: Мгновенный поиск кодов операций склада, регламентов действий ТСД и быстрая фильтрация по категориям (Приемка, Хранение, Сборка, Упаковка, Сортировка, Отгрузка, Брак).
- 🏷️ **Выделитель ШК и Стикеров (`/tools/separator`)**: Пакетная очистка, дедупликация, нормализация и форматирование штрихкодов из таблиц и отчётов с возможностью экспорта в `.txt`.
- 🌓 **Тёмная и Светлая темы**: Переключение тем оформления с сохранением состояния.

## Стек технологий

- **Фреймворк**: Next.js 15+ (App Router)
- **Язык**: TypeScript
- **Стилизация**: Tailwind CSS v4, Lucide Icons, Framer Motion
- **Темизация**: next-themes

## Запуск проекта локально

1. Установите зависимости:
```bash
npm install
```

2. Запустите dev-сервер:
```bash
npm run dev
```

3. Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Сборка для продакшена

```bash
npm run build
npm start
```
